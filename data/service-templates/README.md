# איסוף נתוני טיפולים – מדריך לצוות

כל אחד אוסף נתוני טיפולים ל־**2 דגמים** מתוך חוברת הטיפולים או ספר הרכב של היצרן.
הנתונים האלה הם הבסיס של מנוע הטיפולים, ולכן הם חייבים להיות **מדויקים ומבוססי מקור**.

> אם דגם מגיע בכמה מנועים (בנזין / היברידי / דיזל), בחרו את הגרסה הנפוצה בישראל וציינו אותה בשדה `engine`.
> את שמכם ממלאים בשדה `collectedBy` בתוך קובץ ה־JSON.

## איפה מוצאים את המידע

1. **חוברת הטיפולים / ספר הרכב** (Owner's Manual / Maintenance Schedule) – המקור המועדף.
2. **אתר היבואן או היצרן** – הרבה יצרנים מפרסמים את ספר הרכב כ־PDF.
3. **מוסך מורשה של היבואן** – אפשר לבקש את טבלת הטיפולים.

## איך משתמשים ב־AI (ומה אסור)

- ✅ מותר: להעלות ל־AI את ה־PDF של החוברת ולבקש ממנו לחלץ את טבלת הטיפולים לפורמט ה־JSON.
- ✅ מותר: לבקש ממנו לתרגם או לסדר את הנתונים.
- ❌ אסור: לבקש מה־AI "מה לוח הטיפולים של X" בלי לתת לו את החוברת. מודלים ממציאים מרווחי טיפול ומק"טים בביטחון מלא.
- ✔️ **חובה:** אחרי שה־AI חילץ, לעבור על כל ערך מול החוברת עצמה, ורק אז לשנות `"verified": true`.

## מה לאסוף לכל טיפול

| שדה | הסבר |
|---|---|
| `id` | מזהה קצר באנגלית, למשל `oil-change`, `brake-fluid`, `spark-plugs` |
| `name` | שם הטיפול בעברית |
| `intervalKm` | כל כמה ק"מ (למשל 15000) |
| `intervalMonths` | כל כמה חודשים (למשל 12). הטיפול מגיע לפי מה שקורה **קודם** |
| `firstAtKm` | אם הטיפול הראשון שונה מהשאר (למשל טיפול הרצה ב־1000 ק"מ). אחרת `null` |
| `actions` | רשימת פעולות לביצוע |
| `parts` | חלפים: שם, מק"ט אם מופיע, כמות ומפרט (למשל סוג שמן) |
| `costMin` / `costMax` | טווח מחיר בש"ח לטיפול כולו (חלפים + עבודה) |
| `costSource` | מאיפה המחיר: מחירון יבואן, הצעת מחיר ממוסך, חשבונית וכו'. אם אין מקור, השאירו 0 ושדה ריק |
| `notes` | הערות, למשל "בתנאי נסיעה קשים כל 7,500 ק"מ" |

טיפולים שחשוב לכסות (אם מופיעים בחוברת): שמן ומסנן, מסנן אוויר, מסנן מזגן, נוזל בלמים, מצתים, נוזל קירור, רצועת טיימינג/עזר, נוזל גיר, רפידות ודיסקים (בדיקה), צמיגים (בדיקה/רוטציה).
לקטנועים גם: רצועת הנעה (CVT), גלגלות, שמן גיר סופי, מסנן אוויר של המשנק.

## איך מגישים

1. העתיקו את `_template.json` לקובץ חדש בשם `make-model.json` באותיות קטנות, למשל `toyota-corolla-hybrid.json`.
2. מלאו לפי הדוגמה ב־`_example.json` (הדוגמה מראה את המבנה בלבד – המספרים בה לא אמיתיים).
3. מלאו את `source` במדויק: שם החוברת, מהדורה, עמודים, וקישור אם יש.
4. פתחו branch בשם `data/<model>` ו־PR. מי שאחראי על מסד הנתונים עובר על הקבצים.

## Checklist לפני PR

- [ ] כל הערכים נבדקו מול החוברת
- [ ] `source` מלא (מסמך + עמודים)
- [ ] `verified` שונה ל־`true`
- [ ] הקובץ הוא JSON תקין (אפשר לבדוק ב־jsonlint.com)
- [ ] אין ערכים שהמצאתם או שה־AI המציא
